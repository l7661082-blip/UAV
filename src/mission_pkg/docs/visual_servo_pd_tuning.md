# 视觉伺服 PD 控制器调优指南

## 📋 概述

视觉伺服控制已从**纯P控制**升级为**PD控制（比例-微分控制）**，有效解决了震荡问题。

### 优化内容
- ✅ **PD控制器**：添加微分项(D)提供阻尼，抑制震荡
- ✅ **死区机制**：小误差时停止控制，减少抖动
- ✅ **平滑控制**：基于误差变化率的渐变控制
- ✅ **独立调参**：X/Y/Yaw 三个方向独立的 P 和 D 增益

---

## 🎛️ 参数说明

### 比例增益（P）
控制响应速度，值越大响应越快，但过大会震荡。

```xml
k_p_x="0.0008"      <!-- X方向（横向）比例系数 -->
k_p_y="0.002"       <!-- Y方向（纵向）比例系数 -->
k_p_yaw="0.0015"    <!-- 偏航比例系数 -->
```

### 微分增益（D）
提供阻尼，抑制震荡，值越大阻尼越强。

```xml
k_d_x="0.003"       <!-- X方向微分系数（阻尼） -->
k_d_y="0.006"       <!-- Y方向微分系数（阻尼） -->
k_d_yaw="0.004"     <!-- 偏航微分系数（阻尼） -->
```

**关键关系**：`k_d` 通常设为 `k_p` 的 **2-5倍**

### 死区（Deadzone）
小于此值的误差将被忽略，单位：像素。

```xml
deadzone_x="8.0"    <!-- X方向死区（像素） -->
deadzone_y="8.0"    <!-- Y方向死区（像素） -->
deadzone_yaw="5.0"  <!-- 偏航死区（像素） -->
```

**推荐值**：5-10像素（640x480分辨率）

### 其他参数
```xml
forward_velocity="0.35"          <!-- 前进速度 (m/s) -->
max_velocity="0.3"               <!-- 最大修正速度 (m/s) -->
max_yaw_rate="0.1"               <!-- 最大偏航角速度 (rad/s) -->
align_threshold="10.0"           <!-- 对齐阈值（像素） -->
area_ratio_threshold="0.2"       <!-- 冲刺触发面积占比 -->
sprint_velocity="1.3"            <!-- 冲刺速度 (m/s) -->
sprint_time="1.0"                <!-- 冲刺持续时间 (秒) -->
```

## 🔧 调优步骤

### 1. 先调 P 增益（保持 D=0）

```bash
# 临时关闭微分控制
k_d_x="0.0"
k_d_y="0.0"
k_d_yaw="0.0"
```

**逐步增大 P 增益**，直到系统出现**持续震荡**，记下这个临界值 `P_crit`。

### 2. 加入 D 增益

根据临界 P 值设置：
- **保守**：`P = 0.5 * P_crit`，`D = 2 * P`
- **激进**：`P = 0.6 * P_crit`，`D = 4 * P`

### 3. 微调死区

观察无人机悬停时的抖动：
- 抖动明显 → 增大死区（10-15像素）
- 对准慢 → 减小死区（3-5像素）

### 4. 实际测试

启动任务并观察日志：

```bash
roslaunch mission_pkg hit_balloon.launch
```

关键日志示例：
```
[VisualServo]: ALIGNING - err_x:15.3(dz:7.3) ey:8.2(dz:0.0) yaw_rate:0.045 vz:-0.12
[VisualServo]: APPROACHING - vx:0.28(80%) vy:-0.08 vz:0.05 err_x:12.1(dz:4.1) err_y:6.3(dz:0.0) ratio:0.15
```

## 📊 常见问题

### ❌ 问题1：来回震荡

**原因**：P 增益过大，D 增益不足

**解决**：
- 减小 P 增益（降低 20-30%）
- 增大 D 增益（增加 50-100%）

### ❌ 问题2：响应太慢

**原因**：死区过大，或 P 增益过小

**解决**：
- 减小死区（5像素）
- 适当增大 P 增益（增加 10-20%）

### ❌ 问题3：微小抖动

**原因**：死区过小

**解决**：
- 增大死区（10-12像素）
- 适当增大 D 增益

### ❌ 问题4：过度阻尼（反应迟钝）

**原因**：D 增益过大

**解决**：
- 减小 D 增益（降低 30-50%）

## 💡 工作原理

### PD 控制数学模型

```
输出 = P项 + D项
     = k_p * 误差 + k_d * (误差变化率)
```

- **P项**：根据当前误差提供修正力
- **D项**：根据误差变化趋势提供阻尼力

**物理类比**：就像汽车减震器
- 弹簧（P）：提供恢复力
- 阻尼器（D）：抑制震荡

### 死区原理

```
if |误差| < 死区:
    输出 = 0
else:
    输出 = PD(误差 - 死区)  # 线性衰减
```

**作用**：避免在目标附近微小抖动，节省能量，提高稳定性。
